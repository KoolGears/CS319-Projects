# Student Study Planner

A browser-based course, assignment, and grade dashboard built with HTML, CSS, and vanilla JavaScript.

## Run

Open `index.html` directly, or serve this folder with `python -m http.server 8000`.

## Features

- Add, edit, and delete courses.
- Add several courses at once with one course per line (`Name | Code | Instructor`).
- Add, edit, delete, and search assignments.
- Cycle assignment status from the checkbox, or change status and priority in the edit form.
- View upcoming deadlines, completion progress, and average course grade.
- Persist all data in browser `localStorage`, including after a refresh.
